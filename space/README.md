Type a skill for a Unitree G1 humanoid. Nemotron 3 Ultra (via Nebius Token Factory) writes the reinforcement-learning
reward, the code is compiled and evaluated on the robot's measured body geometry, and a plot shows how the reward
responds as the right hand rises from the hip to full reach. Compile errors are sent back to Ultra for self-repair.

Full project, training runs and videos: https://github.com/VishwaVenkatesh/nemotron-reward-engineer
